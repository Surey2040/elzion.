# ELZION React + Express

The original ELZION visual design, responsive rules, scroll sequences and animations are preserved exactly. React owns the frontend mount lifecycle, while Express provides an isolated backend API scaffold.

## Install

```bash
npm run install:all
```

## Run

Frontend:

```bash
npm run dev:frontend
```

Backend (separate terminal):

```bash
npm run dev:backend
```

Frontend: http://localhost:5173
Backend health: http://localhost:5000/api/health
